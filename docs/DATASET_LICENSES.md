# Dataset Licenses and Attribution

Source assessment as of 2026-10-11. This records project-level evidence; it is not legal advice. Recheck each source’s current terms before redistribution or commercial use.

## Open Images V7

- Official terms: [license facts](https://storage.googleapis.com/openimages/web/factsfigures_v7.html#licenses) and [download instructions](https://storage.googleapis.com/openimages/web/download_v7.html).
- Annotation files: CC BY 4.0; credit Google LLC and cite Open Images and the relevant annotation papers.
- Images are listed as CC BY 2.0, but Google disclaims warranties about the image licenses. The 100 selected validation images were downloaded only when their per-image metadata listed CC BY 2.0. Preserve each author, source URL, landing URL, license, and license URL.
- The mask PNGs are official annotations; the aligned copies use nearest-neighbor resizing only. Source masks and annotations remain in separate directories.
- Boxes and points are not masks. No picture-frame label is converted to painting.

## ContactHands

- Official source: [ContactHands project page](https://vision.cs.stonybrook.edu/~supreeth/ContactHands_data_website/).
- The page describes a roughly 4.5 GB hand/contact release but does not state image-level reuse or redistribution terms.
- The companion [ContactHands code repository](https://github.com/cvlab-stonybrook/ContactHands) has an MIT license for repository code. That does not grant image rights for the separately hosted dataset.
- No ContactHands image was downloaded. Attribution to the [paper](https://proceedings.neurips.cc/paper_files/paper/2020/hash/595373f017b659cb7743291e920a8857-Abstract.html) is still appropriate if the dataset is later lawfully obtained: Narasimhaswamy et al., “Detecting Hands and Recognizing Physical Contact in the Wild,” NeurIPS 2020.

## ContactPose

- Official source and [license statement](https://github.com/facebookresearch/ContactPose#licensing).
- Code and non-3D-model data are MIT licensed. Each 3D model has an individual license described in release metadata.
- The repository’s sample archive is linked via Google Drive. The inspected page presented a sign-in prompt, and no anonymous size preflight was available; no archive was acquired.
- Cite Brahmbhatt et al., “ContactPose: A Dataset of Grasps with Object Contact and Hand Pose,” ECCV 2020. Generic object contact is not harmful painting contact.

## HOI4D

- Official [project page](https://hoi4d.github.io/) states [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/): attribution and noncommercial use are required.
- The linked video archives did not expose a verified bounded per-sequence size during this run. No files were downloaded.
- Cite Liu et al., “HOI4D: A 4D Egocentric Dataset for Category-Level Human-Object Interaction,” CVPR 2022.

## The Metropolitan Museum of Art Open Access

- Official [API](https://metmuseum.github.io/) and [terms](https://www.metmuseum.org/policies/terms-and-conditions).
- The API exposes corresponding high-resolution Open Access images for public-domain records. Acquisition filters required `isPublicDomain=true`, `classification=Paintings`, and the official HTTPS image host.
- The ten acquired artwork images are covered by [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Attribution is not required by CC0; the project retains object ID, artist, title, object URL, API record, credit line, SHA-256, and license metadata for provenance.
- Art images are used as source material for synthetic composites only. Their image boundary is not a gallery-frame annotation.

## V-COCO and COCO

- V-COCO action/role annotations are from the official [MIT-licensed repository](https://github.com/s-gupta/v-coco). Keep its copyright/license notice and cite the release papers.
- V-COCO JSON references COCO image IDs but contains no image pixels. COCO annotation terms are [CC BY 4.0](https://cocodataset.org/#termsofuse); source images are third-party works with separate terms. No COCO images were downloaded.

## MediaPipe Hand Landmarker

- The official [task guide](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker) links the task bundle. The [official model card](https://storage.googleapis.com/mediapipe-assets/Model%20Card%20Hand%20Tracking%20%28Lite_Full%29%20with%20Fairness%20Oct%202021.pdf) states Apache License 2.0.
- The 7,819,105-byte `.task` bundle is a pretrained inference asset, not labeled training data. The project records its source and checksum in `dataset/metadata/acquisition_manifest.json`.
- The optional Python package is separately declared in `requirements-hands.txt`; the project tests it in isolated `.venv-hands` to avoid modifying the primary YOLO environment.

## Synthetic and custom data

- Synthetic scene labels and masks are generated by this project and are explicitly marked `SYNTHETIC`. They combine CC0 Met art with stylized vector hand/tool shapes and a flat vector wall; there are no real cutouts or gallery photos.
- No user webcam video or custom user recording is present. The system does not claim rights for data that was not acquired.
